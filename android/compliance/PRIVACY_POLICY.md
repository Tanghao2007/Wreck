# 隐私政策与数据保护声明 (Privacy Policy & Data Compliance)

**版本号**: 2.0.0  
**生效日期**: 2026年11月5日  
**适用范围**: 自适应实时电影级调色引擎 (Adaptive Grading Engine) 及其 Android 原生应用 / SDK

---

## 一、核心原则：纯端侧计算与零数据回传 (Zero-Data Transmission Guarantee)

本产品本着“用户数据绝对安全、最小化权限、零网络侵入”的核心设计原则，向所有用户及监管机构郑重声明：

1. **绝对零网络请求 (Zero Network Communication)**:
   - 本应用及 SDK 的安装清单（`AndroidManifest.xml`）**明确不声明、不申请任何网络相关权限**（包括但不限于 `android.permission.INTERNET` 与 `android.permission.ACCESS_NETWORK_STATE`）。
   - 调色算法引擎为纯 C 语言原生内核，无任何内建网络通讯库、打点 SDK 或第三方广告分析框架。
   - 无论设备处于 Wi-Fi、蜂窝移动网络还是飞行模式，本引擎的所有计算与滤镜渲染行为均 100% 局限于设备端本地 CPU / 内存中完成。

2. **零图像/视频上传与外流**:
   - 相机预览画面（YUV420_888 硬件流）直接经由 JVM DirectByteBuffer 直通至 Native 内存进行并行色调映射与像素着色，**数据在渲染完毕后即在下一帧刷新时原地覆写销毁**。
   - 算法绝不缓存未调色的原图，绝不在后台静默存储用户相机镜头捕捉的任何视频帧序列。

3. **零人脸特征/生物识别数据提取**:
   - 算法中的“肤色检测与色彩保护（Skin Tone Preservation）”基于通用 RGB/YCbCr 色彩空间统计学阈值与椭圆分布模型计算，属于纯无监督数学概率掩模。
   - **绝不提取人脸关键点、绝不提取面部几何拓扑、绝不进行人脸识别或身份比对**，完全符合国际生物识别特征保护相关法律法规。

## 二、系统权限申请及使用说明

本应用严格遵循 Android 权限最小化与动态授权规范：

| 权限名称 | 对应 API 级别 | 申请目的与使用场景 | 是否必选 |
|:---|:---|:---|:---|
| `android.permission.CAMERA` | 全版本 (运行时动态权限) | 仅用于调用手机前置/后置镜头获取实时取景画面并在屏幕上展示调色效果。若用户拒绝授权，应用将无法打开实时取景流，但可离线导入静态图片进行调色。 | **必选** (仅在实时取景模式下) |
| `android.permission.WRITE_EXTERNAL_STORAGE` | Android 7.0 ~ 9.0 (API 24~28) | 仅在用户**主动点击拍照快门键**时，将调色后的成品照片保存至手机公开相册目录 (`DCIM/GradingApp/`)。 | **可选** (仅在 Android 9.0 及以下系统拍照保存时申请) |
| 分区存储 (Scoped Storage) | Android 10+ (API 29+) | 适配 Android 标准 `MediaStore.Images` API 与应用私有目录 (`context.getExternalFilesDir`)，**无需声明任何存储危险权限**即可无感保存照片与配方。 | **原生免权限** |

## 三、法律合规对照表 (Compliance Cross-Reference)

### 1. 《中华人民共和国个人信息保护法》(PIPL)
- **知情同意原则**: 在用户首次启动应用时弹出标准权限声明弹窗，明确展示相机调用用途，并支持用户随时在系统设置中撤回权限。
- **最小必要原则**: 仅使用与相机实时画面色彩矩阵解算直接相关的内存资源，不读取联系人、通讯录、位置、设备唯一标识符（IMEI/OAID/MAC）等任何与调色无关的硬件信息。

### 2. 欧盟通用数据保护条例 (GDPR)
- **Privacy by Design (从设计之初保障隐私)**: 算法核心完全去除了对云端服务与中心化服务器的依赖，天然阻断了数据出境与跨境传输的技术路径。
- **Data Minimization (数据最小化)**: 帧数据在内存中即时消费即时销毁，生命周期低于 25 毫秒，无本地隐蔽落盘。

### 3. Google Play 用户数据合规政策 (Google Play User Data Policy)
- **Camera Data Usage Disclosure**: 明晰标注相机权限专用于用户主动拍摄的照片色彩增强处理。
- **Prominent Disclosure**: 在进入相机页面前展示用户可见的权限使用场景浮层。
